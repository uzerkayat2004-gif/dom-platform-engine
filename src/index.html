Only authenticated staff can place orders. Only managers can approve refunds above the set limit. No customer data leaves this device. Maximum three failed login attempts then lockout. All payment data is encrypted at rest. Session timeout after 15 minutes of inactivity.
⚙️ behavior.md ▼
Always confirm before deleting any item. Always show price before processing payment. Never process the same order twice. Always notify the kitchen within 30 seconds of order placement. Display order summary before final confirmation. Auto-save all changes every 60 seconds.
🚫 limits.md ▼
Maximum single transaction value: ₹50,000. Maximum discount without manager approval: 30%. Operating hours: as set by owner. Maximum items per order: 50. Maximum concurrent active orders: 100.
✅ skills.md ▼
